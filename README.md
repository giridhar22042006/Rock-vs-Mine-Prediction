# Rock vs Mine Prediction using Machine Learning

## Overview

This project classifies whether an object detected by SONAR is a **Rock (R)** or a **Mine (M)** using Logistic Regression.

## Dataset

- Sonar Dataset
- 208 samples
- 60 numerical features
- Target:
  - R = Rock
  - M = Mine

## Technologies Used

- Python
- NumPy
- Pandas
- Scikit-learn
- Jupyter Notebook

## Machine Learning Algorithm

- Logistic Regression

## Project Workflow

1. Import Libraries
2. Load Dataset
3. Data Analysis
4. Train-Test Split
5. Train Logistic Regression Model
6. Evaluate Accuracy
7. Predict Rock or Mine
